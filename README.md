# Belistory Games 官网(vanithun.github.io)

GitHub Pages 用户站点,内容与本项目主仓库 `website/` 目录保持同步。

## 文件

- `index.html` — 首页
- `privacy.html` / `terms.html` — 隐私政策 / 服务条款(商店页和 Google Play 需要)
- `app-ads.txt` — AdMob 验证文件。**拿到 AdMob publisher ID 后,把 `pub-0000000000000000` 替换为真实 ID**(AdMob 后台 → 账户 → 账户信息),格式保持不变。

## 更新流程

在主仓库改 `website/` 后,重新拷贝到这里提交推送即可。
